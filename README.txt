# Siria Spallotta — Portfolio

Portfolio one-page gratuito in HTML/CSS/JS.

## Prima di pubblicarlo
1. Apri `index.html`.
2. Sostituisci `inserisci-la-tua-email@example.com` con la tua email professionale.
3. Salva.

## Pubblicazione gratuita con GitHub Pages
1. Crea un nuovo repository pubblico su GitHub, ad esempio `siria-portfolio`.
2. Carica `index.html`, `style.css` e `script.js` nella root del repository.
3. Vai in Settings → Pages.
4. In Build and deployment scegli `Deploy from a branch`.
5. Seleziona `main` e `/ (root)`, poi Save.
6. Dopo la pubblicazione avrai un link del tipo:
   `https://siriaspallotta4-ops.github.io/siria-portfolio/`

Il progetto ATELIER 27 è già collegato al portfolio.
